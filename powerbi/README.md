# Olist E-Commerce Logistics Performance Dashboard

## Overview
This Power BI dashboard analyzes Olist e-commerce order and delivery performance. It provides insights into order status, delivery delays, delivery duration, monthly trends, and regional order distribution.

## Dataset
- Source: Olist E-Commerce Dataset
- Main table: Orders
- Customer table: olist_customers_dataset
- Total orders: 99,441
- Granularity: One row per order

## Dashboard Pages

### 1. Executive Overview
- Total Orders
- Delivered Orders
- Cancelled Orders
- Late Orders
- Monthly Order Trends
- Average Delivery Time by Month
- Orders by Customer State
- Order Status Distribution
- On-Time vs Late Orders

### 2. Delivery Performance
- Average Delivery Delay by Month
- Average Actual Delivery Time
- Average Estimated Delivery Time
- Date and Order Status Filters

### 3. Operational Analysis
- Average Carrier Handover Time
- Average Carrier-to-Customer Time
- Orders by Customer State
- Order Status Distribution
- Cancelled Orders
- Customer State, Order Status, and Date Filters
