# Olist E-Commerce Logistics Performance Dashboard

## Overview
This Power BI dashboard analyzes Olist e-commerce order and delivery performance. It provides insights into order status, delivery delays, monthly trends, regional performance, and order value.

## Dataset
- Source: Olist E-Commerce Dataset
- Table: `order_analytics`
- Total records: 99,441
- Granularity: One row per order

## Dashboard Features
- Total Orders
- Delivered Orders
- Late Orders
- Late Delivery Rate
- Cancellation Rate
- Monthly Order Trends
- Average Delivery Time by Order Status
- Monthly Late Delivery Analysis
- Orders by Customer State
- Total Order Value by Customer State
- Order Status Distribution

## Tools Used
- Microsoft Power BI
- MySQL
- DAX
- Power Query
